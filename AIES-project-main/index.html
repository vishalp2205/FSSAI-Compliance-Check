  • Date & Batch Parser: Mfg, Expiry, Best Before parsing
  • Nutritional Parser: Extracts 9 core mandatory nutrient values / 100g

FSSAI 2020 Statutory Rule Catalogue (R01–R10)

Mapped to Food Safety and Standards (Labelling and Display) Regulations, 2020 & Gazette Amendments

R01

License Format

Must be exactly 14 digits starting with 1 (Central) or 2 (State).

^[12]\d{13}$
R02

License State Code

Digits 2–3 must map to an authorized Indian state code (01–37).

State Code Verification
R03

License Presence

14-digit candidate must appear prominently on the packaging.

Mandatory Presence
R04

FSSAI Logo Verification

Statutory FSSAI insignia detected via YOLO11n object detection.

YOLO11n Class 2
R05

Dietary Mark Present

Mandatory declaration of Vegetarian or Non-Vegetarian status.

YOLO11n Class 0/1
R06

Dietary Mark Colour

Veg = Green circle in green square. Non-Veg = Brown triangle in brown square.

HSV Space Validation
R07

Mark vs Ingredients Conflict

Cross-verification ensuring Veg marks contain no animal-derived ingredients.

Cross-Consistency
R08

Allergen Declaration

Mandatory declaration of 8 major allergens in a dedicated "Contains" line.

Regulation 6 (8 Classes)
R09

Date Marking

Explicit "Use by Date", "Expiry Date", or "Best Before" with valid date.

Regulation 7 Date Check
R10

Nutritional Information Panel

Energy, Protein, Carbs, Total/Added Sugars, Fat, Saturated/Trans Fat, Sodium.

Regulation 8 (9 Nutrients)
